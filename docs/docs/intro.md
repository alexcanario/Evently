# Introduction

Welcome to the **Evently API** documentation!

Evently is a modern event management platform built with **.NET 10** and **PostgreSQL**.

## Features

- 🎯 **Event Management** - Create, update, and manage events
- 🌐 **Multi-language Support** - English, Portuguese, Spanish
- 🐳 **Docker Support** - Full containerized deployment
- 📚 **Interactive API Docs** - Scalar and Docusaurus integration
- 🔒 **Type-safe** - Built with modern C# 14

- **.NET 10** - Latest .NET framework
- **PostgreSQL** - Robust database
